# Чек-лист соглашений

## Для текущей версии

- Пользовательское соглашение.
- Политика конфиденциальности.
- Согласие на уведомления через бота.
- Медицинский дисклеймер.
- Описание тестовых и модельных данных.

## Для пилота с организацией

- Договор пилота.
- Матрица ответственности за контент.
- NDA, если партнер передает непубличные регламенты.
- SLA для доступности и реакции на инциденты.
- Поручение на обработку персональных данных, если команда продукта обрабатывает данные от имени партнера.

## Отдельно, если появится загрузка медицинских документов

- Отдельное согласие на обработку сведений о здоровье.
- Правовое основание обработки специальных категорий персональных данных.
- Регламент удаления документов после обработки.
- Запрет на передачу содержимого документов в сторонние сервисы без отдельного основания.
