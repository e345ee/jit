# Функционал

## Must Have

1. Каталог ситуаций
   - Категории: диагностика, операции, инвалидность, налоговый вычет, госпитализация, лекарства.
   - Поиск по названию, документам, ключевым словам.
   - Короткий список релевантных карточек.

2. Карточка ситуации
   - Название.
   - Краткое описание.
   - Шаги.
   - Объяснение, почему шаг важен.
   - Где получить.
   - Срок действия документа или результата.
   - Частые ошибки.
   - Источник и дата актуальности.

3. Дерево решений
   - 1-2 вопроса перед показом финального списка шагов.
   - Адаптация без сохранения персональных данных.
   - Пример для "МРТ с контрастом": аллергия на контраст, есть ли направление, регион или тип учреждения.

4. Локальный чек-лист
   - Отметка выполненных шагов.
   - Хранение на устройстве.
   - Сброс прогресса по карточке.

5. База знаний
   - Короткие карточки-объяснения.
   - Поиск.
   - Связь с ситуациями.

6. MAX bot entrypoint
   - Старт.
   - Кнопка открытия mini app.
   - Краткая помощь.

## Should Have

1. Напоминания через бота
   - Только по явному согласию пользователя.
   - Напоминание о сроке без диагноза и медицинских данных.
   - Возможность отменить напоминание.

2. История просмотренных карточек
   - Локально на устройстве.
   - Без отправки на сервер.

3. Версионирование контента
   - Пользователь видит дату актуальности.
   - Mini app умеет обновить справочник.

## Could Have

1. Мультиязычные карточки для иностранных граждан.
2. Сравнение путей: ОМС, ДМС, платно.
3. Экспорт чек-листа в изображение или сообщение самому себе.
4. Подсказки по доступности: крупный шрифт, контрастный режим.

## Границы текущей версии

1. Медицинская интерпретация анализов.
2. Диагностические рекомендации.
3. Хранение медицинских документов.
4. Интеграция с реальными медицинскими ИС.
5. Автоматическое оформление госуслуг от имени пользователя.

## Базовый набор демонстрационных маршрутов

1. МРТ с контрастом.
2. Оформление инвалидности через МСЭ.
3. Налоговый вычет за лечение.
4. Госпитализация: что подготовить.
5. Льготные лекарства: где узнать право и порядок получения.
