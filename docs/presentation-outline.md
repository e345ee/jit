# План презентации

1. Служебный слайд
   - ссылка на MAX bot/mini app;
   - ссылка на репозиторий и commit hash;
   - команда запуска;
   - тестовые данные;
   - краткий сценарий проверки.

2. Пользователь и проблема
   - пациент перед МРТ с контрастом;
   - требования разбросаны между источниками;
   - ошибка приводит к переносу записи.

3. As Is
   - врач, регистратура, лаборатория, сайт, Госуслуги;
   - ручная сверка сроков и документов.

4. To Be
   - одна карточка маршрута;
   - 1-2 уточнения;
   - локальный чек-лист и нейтральное напоминание.

5. Демо
   - открыть bot;
   - открыть mini app;
   - найти "МРТ с контрастом";
   - ответить на вопросы;
   - отметить шаг;
   - открыть детали;
   - включить напоминание.

6. Архитектура
   - web;
   - api;
   - bot;
   - content;
   - optional reminders.

7. Данные и безопасность
   - не храним диагнозы;
   - чек-лист локальный;
   - источники и даты актуальности;
   - токены только в `.env`.

8. Эффект
   - меньше звонков;
   - меньше переносов;
   - понятнее путь пациента.

9. Масштабирование
   - ядро одинаковое;
   - меняются карточки, региональные правила и источники.

10. Пилот и продажа
    - диагностический центр;
    - 2-4 недели;
    - QR/deeplink;
    - отчет по метрикам.

11. Риски и ограничения
    - контент требует проверки;
    - внешние медицинские ИС не подключены в текущем контуре;
    - сервис не заменяет специалиста.
