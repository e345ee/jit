# Дизайн-система

## Образ

Свежий медицинский помощник внутри MAX: сначала телефон, потом все остальное. Интерфейс должен ощущаться как короткий маршрут в чате, а не как desktop-портал или админка.

## Типографика

Основной шрифт: `Onest` с системным fallback. Причина: хорошая кириллица, дружелюбная форма, меньше ощущения шаблонного SaaS. Не смешиваем гарнитуры внутри mini app.

## Палитра

Используем только эти цвета в UI:

- `#172b3a` ink - основной текст и темные элементы;
- `#345061` text - вторичный плотный текст;
- `#748796` muted - пояснения и метаданные;
- `#d8e4e8` line - обычные границы;
- `#f6faf8` canvas - общий фон;
- `#ffffff` surface - панели и строки;
- `#eef6f3` soft - вторичные панели;
- `#138f7a` teal - здоровье, выполнено, основной бренд-акцент;
- `#2d6cdf` blue - навигация, поиск, активные состояния;
- `#eef4ff` blue-soft - мягкий активный фон;
- `#a96f1d` amber - осторожность и дисклеймер;
- `#fff8e8` amber-soft - фон дисклеймера;
- `#bd4b45` danger - ошибки.

Не добавляем новые оттенки без отдельного решения команды.

## Компоненты

- Радиус: `14px` для мобильных карточек и контролов, `999px` для chips.
- Карточки не вкладывать в карточки.
- Основная сетка: один вертикальный поток на ширине телефона. На desktop показываем phone preview, а не растянутый dashboard.
- Главная навигация mini app: нижняя панель `Поиск / Маршрут / Детали`.
- Иконки: `lucide-react`, без самодельных SVG.
- Кнопки действий: иконка для чек-листа и напоминаний, текстовые кнопки только для явных команд.
- Не показывать технические enum-ы (`synthetic`, `diagnostics`) в интерфейсе.
- Не добавлять декоративные тени, градиенты и иллюстрации без продуктовой функции.

## Каналы

Mini app:

- полный сценарий;
- вопросы;
- локальный чек-лист;
- детали шага;
- источники.

MAX bot:

- быстрый ответ по справочнику;
- 3-5 шагов;
- дата актуальности и статус данных;
- кнопка открытия mini app.

Оба канала используют один контентный API.
