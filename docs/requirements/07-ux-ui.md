# 07. UX/UI

## Требование

Основной пользовательский путь должен соответствовать приоритетному сценарию, быть понятным без дополнительных пояснений, без лишних шагов, тупиков и противоречивых переходов. Интерфейс должен сообщать о загрузке, результате и ошибке.

## Применение к проекту

Экранная модель:

1. Поиск и категории.
2. Карточка справочника.
3. Детали шага.
4. База знаний.
5. Опциональное напоминание.

## UX-правила

- Короткие названия категорий.
- В карточке сначала результат и следующий шаг, затем детали.
- Каждый шаг объясняет "зачем".
- Сроки выделяются явно.
- Ошибка содержит следующий доступный шаг.

## Проверка

- Пользователь находит "МРТ с контрастом" за 1-2 действия.
- На карточке виден чек-лист.
- Детали шага открываются без потери контекста.
- При пустом поиске есть подсказка, что можно попробовать.
