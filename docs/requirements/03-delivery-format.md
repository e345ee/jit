# 03. Формат сдачи

## Требование

Нужны работающее решение в MAX, зафиксированная версия исходного кода, README, файл зависимостей, Docker-конфигурация и презентация PDF.

## Применение к проекту

В репозитории должны появиться:

- `README.md`
- `package-lock.json` или аналог lock-файла
- `Dockerfile` для локально запускаемых компонентов
- `compose.yaml`
- `.dockerignore`
- `.env.example`
- `openapi.yaml`, если будет собственный API
- `DATA-API.yaml`, если API нужно проверять автоматически

## Проверка

- Есть commit hash сдаваемой версии.
- README содержит одну команду запуска.
- Описаны порты, env, зависимости, тестовые данные, сценарий проверки, ожидаемое поведение и ограничения.
