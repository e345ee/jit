# 05. Данные, приватность, безопасность

## Требование

Нельзя размещать рабочие токены, пароли, ключи и другие секреты в репозитории. Нужно описать работу с данными, источники, интеграции и ограничения. В медицинских сценариях нельзя использовать реальные персональные или медицинские данные без законных оснований.

## Применение к проекту

Проект минимизирует данные:

- Чек-лист хранится локально на устройстве.
- Контент справочника не содержит персональных данных.
- Напоминания хранят только chat id, дату и нейтральный текст напоминания.
- Диагнозы, результаты анализов и документы не хранятся.

## Безопасность

- Токены только в `.env`.
- `.env` игнорируется git.
- `.env.example` содержит только плейсхолдеры.
- Логи не содержат персональных и медицинских данных.
- API валидирует входные параметры.

## Проверка

- Поиск секретов перед сдачей.
- Документация явно говорит, какие данные тестовые.
- Пользователь видит источник и дату актуальности контента.
