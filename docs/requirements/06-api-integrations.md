# 06. API и интеграции

## Требование

Собственный API не обязателен и сам по себе не дает дополнительных баллов. Если API используется, нужны HTTPS-адрес, OpenAPI 3.0/3.1, тестовые данные и DATA-API.yaml.

## Применение к проекту

API нужен для контента, поиска, версий и напоминаний. Реальные внешние интеграции на MVP не обязательны. Если используются модельные данные, это должно быть прямо указано.

## Контракты

- `GET /health`
- `GET /content/version`
- `GET /situations`
- `GET /situations/{id}`
- `GET /knowledge`
- `POST /reminders`
- `DELETE /reminders/{id}`

## Проверка

- OpenAPI соответствует фактическим ответам.
- Ошибки возвращают предсказуемые коды.
- Повторное создание напоминания не плодит дубликаты.
- Документация отделяет реальные и модельные интеграции.
