# 04. Docker и воспроизводимость

## Требование

Решение должно запускаться воспроизводимо через Docker. Сборка локальных компонентов должна занимать не более 5 минут без учета первичной загрузки базовых образов.

## Применение к проекту

MVP должен запускаться одной командой:

```bash
docker compose up --build
```

## Компоненты

- `web`
- `api`
- `bot`
- `worker`
- `postgres`
- `redis`

## Проверка

- Контейнеры стартуют без ручных действий.
- Healthcheck проходит.
- Mini app доступен локально.
- README описывает, какие части требуют публичного HTTPS для проверки в MAX.
